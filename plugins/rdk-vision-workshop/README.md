# 四小时相机与 BPU 视觉 Workshop

在 Studio 中编排已有驱动点亮、ISP、数据、GPU 微调、PTQ、X5 BPU 和实时检测。总时长240分钟，含10分钟休息。此包提供课程技能和两个只读MCP工具；不会安装SDK、提供GPU、连接相机或启动训练。

## 安装和连接

1. 解压整个包，在 Studio AI→扩展中心→添加→从目录导入插件，选择含 plugin.json 的目录。不要只复制 SKILL.md。
2. 确认插件已启用。部分宿主仅在插件中心显示MCP和技能，原生Moss未必自动注入；不能据1个MCP图标判断已经可调用。
3. 从已经安装/保留的稳定目录运行 `node <插件目录>/mcp/studio-config.mjs`，把输出JSON导入 Studio 设置→MCP Servers→导入配置。生成器仅输出配置，不读取凭据或修改既有MCP。使用宿主实际可用Node。
4. 配置仅开放vision_course_plan和vision_course_stage为readonly，其余默认deny。导入前确认合并方式，保留其它服务。不要用开发仓库路径替代安装副本。
5. 在Studio对话要求：“调用 vision_course_plan 读取四小时课程计划，并列出当前环境缺口，只读，不启动设备或训练。”实际缺设备/模型/账号时由宿主拒绝，不伪造就绪。

课程计划工具也返回本包操作稿和检测交接说明，使未自动注入SKILL的宿主仍能通过已授权工具取得完整方法。工具返回planning_only/not_executed不是执行回执。

## 执行前准备

相机原子服务及实际授权adapter、单设备独占、完整基线与恢复；GPU项目和已标注数据；匹配X5工具链、校准图、模型/labels/前后处理；检测管线中tuning实际回读和新图。缺项明确保留，不把原装demo或备用模型当本组端到端成果。

本次软件验收与实机成绩分别报告。当前未认证整课、训练质量、BPU性能或画质；历史成功不能证明当前在线。
